** TODO [#B] Add runtime validation when reading history file
   *Purpose:* Fail fast with clear error messages if history file is corrupted.

   Currently ~read-history~ trusts that the file contains valid EDN in the
   expected shape. A corrupted or hand-edited file could cause confusing errors
   deep in the matching logic.

   *Location:* src/robot_disco/robonona/history.clj

   *Fix:* Validate against ~::state~ spec after reading:
   #+BEGIN_SRC clojure
   (defn read-history [file-path]
     (if (.exists (io/file file-path))
       (let [state (edn/read-string (slurp file-path))]
         (if (spec/valid? ::state state)
           state
           (throw (ex-info "Invalid history file"
                           (spec/explain-data ::state state)))))
       {::pairing-history {}}))
   #+END_SRC
